## Review Focus

1. **A correction or Undo of the checkout dart after the try has rolled over.** Undo of a committed visit restores `committedState`, so the reopened visit must refold back to the old try. Task 2 pins this with a refold test.
2. **Give up with darts open.** The engine discards the open visit before committing the action. The try must end as missed, with the open darts counted, and the turn must pass on. Task 3 tests this.
3. **Players finishing their tries at different times in multiplayer.** A finished seat must be skipped, and the game must end only when every seat is done. Task 2 tests this.
4. **A target above 170**, where `checkoutHint` returns null. There must be no crash and no route slots; the hint line falls back to "Score N to make it". Tasks 2 and 6 test this.
5. **A forfeit in multiplayer before anyone has made a checkout.** `summarize` must place the seats without a winner. Task 4 tests this.

```ts
// How a dart scores against what's left: X01's in/out rules, shared by every countdown game (X01, 121).
import type { Dart } from '../session/types.js'

export type OutMode = 'straight' | 'double' | 'master'
export type BullValue = '25_50' | '50_50'

export function effectiveDartScore(dart: Dart, bullValue: BullValue): number {
  const { number, multiplier } = dart.segment
  if (multiplier === 0) return 0
  if (number === 25 && bullValue === '50_50') return 50
  return dart.score
}

// The bull counts as a double however it is reported (Board Manager and manual
// entry send number 50 with multiplier 1; its score is 50 either way).
export const isDouble = (dart: Dart) => dart.segment.multiplier === 2 || dart.segment.number === 50

/** The dart may open (check-in) or finish (check-out) a player under the mode. */
export function meetsMode(dart: Dart, mode: OutMode): boolean {
  if (mode === 'straight') return true
  if (mode === 'double') return isDouble(dart)
  return isDouble(dart) || dart.segment.multiplier === 3
}

/** Nothing can finish from 1 unless any dart may finish. */
export const deadEnd = (score: number, outMode: OutMode) => score === 1 && outMode !== 'straight'

/** The score left after `dart`, or 'bust' (below 0, a dead-end 1, or 0 without the out rule). */
export function scoreDart(left: number, dart: Dart, outMode: OutMode, bullValue: BullValue): number | 'bust' {
  const next = left - effectiveDartScore(dart, bullValue)
  if (next < 0 || deadEnd(next, outMode) || (next === 0 && !meetsMode(dart, outMode))) return 'bust'
  return next
}
```

Rules the reducer implements (from the spec):

- **`dart.detected`.** Ignore it when `phase === 'finished'`, `bust`, or `left === 0`; then count only `visitDarts + 1`. Otherwise:
  - If `checkoutHint(left, outMode, 1)` returns `[label]`, the dart is an attempt: `attempts[label]++`.
  - `scoreDart(left, dart, outMode, '25_50')`. On `'bust'`, set `bust = true` and `left = visitStartLeft`.
  - On 0, `hits[label]++`, where `label` is that same hint label, or `dartLabel(dart.segment)` for a straight-out finish that had no one-dart hint.
  - Clear `lastResult` on every applied dart.
- **`visit.opened`.** `visitStartLeft = seats[cp].left`, `visitDarts = 0`, `bust = false`.
- **`takeout.finished` / `visit.cleared`** run `endVisit(s, made = left === 0)`:
  - `used`: `made ? seat.darts + visitDarts : seat.darts + 3`. A visit that doesn't check out uses all 3 darts.
  - `scored`: `visitStartLeft - left`.
  - The try is over when `made || used >= cfg.dartsPerTry`. Then push `{ target, made, darts: used, finish }`. `finish` is the finishing label on a make, else null.
  - Then call `nextTarget`, reset `left`/`darts`/`visits` for the new target, and set `lastResult`.
  - Otherwise store `darts = used` and `visits = [...visits, scored]`.
  - Then call `advance(s)`: the next turn in `order` whose seat has `tries.length < cfg.tries`. If there is none, set `phase = 'finished'` and `winner = rankWinner(s)`. Set `visitStartLeft` to the new current seat's `left`, `visitDarts = 0`, `bust = false`.
- **`rankWinner`.** The seat with the highest made target, then more checkouts, then fewer darts over made tries, then the lower seat index. Export `compareSeats(a: P121Seat, b: P121Seat): number` (negative: `a` ahead) for Task 4. It leaves out the seat index, so equal seats compare 0 and share a placement. Only `rankWinner` falls back to the lower index.
- **`nextTarget`:**
  ```ts
  export function nextTarget(t: { target: number; made: boolean; darts: number }, cfg: P121Config, floor: number) {
    const lockedFloor = cfg.lock && t.made && t.darts <= 3 ? Math.max(floor, t.target) : floor
    if (t.made) return { target: t.target + 1, floor: lockedFloor }
    const missed = cfg.missRule === 'reset' ? cfg.startTarget : cfg.missRule === 'down' ? t.target - 1 : t.target
    return { target: Math.max(missed, cfg.startTarget, floor), floor }
  }
  ```
- **`dartLabel`:** `0`/multiplier 0 → `'Miss'`; 50, or 25 with multiplier 2 → `'Bull'`; 25 → `'25'`; then `T${n}`, `D${n}`, or `${n}`.
- **`init(cfg, players)`:** each seat gets `{ tries: [], target: cfg.startTarget, left: cfg.startTarget, darts: 0, visits: [], floor: cfg.startTarget, attempts: {}, hits: {} }`. `order` is `[0 … n-1]`, `turn: 0`, `currentPlayer: 0`, `visitStartLeft: cfg.startTarget`, `phase: 'game'`, `winner: null`, `lastResult: null`.
- **`version: 1`.** `defaultConfig` holds the Global Constraints defaults, without `bullOff` (`withBullOff` adds it).
- **`configMeta`** for `startTarget`, `tries`, `dartsPerTry`, `outMode`, `missRule` and `lock`:
  - `startTarget`: 81 / 101 / 121.
  - `tries`: 5 / 10 / 20.
  - `dartsPerTry`: 6 / 9 / 12.
  - `outMode`: the same labels as X01's `outMode`.
  - `missRule`: "Back to start" / "Down one" / "Stay".
  - `lock`: Off / On, with the tooltip "A target checked out in 3 darts or fewer becomes a floor: a miss never drops you below it."
  - `bullOff` comes from the wrapper.

- `highestReached`: the max of every try's target and the seat's open `target`. "Reached 125" after 124 was made.

  - `avgDarts` (the decimal format X01 uses for averages, `lower`)

```ts
export async function getBestStat(db: Kysely<Database>, userId: string, mode: string, key: string) {
  const value = sql<number>`(me.stats->>${key})::float8`
  const row = await finishedGames(db)
    .innerJoin('game_players as me', 'me.session_id', 'gs.id')
    .select(value.as('value'))
    .where('me.user_id', '=', userId)
    .where('gs.game_id', '=', mode)
    .where(sql`me.stats ? ${key}`)
    .orderBy(value, 'desc')
    .orderBy('gs.finished_at', 'asc')
    .limit(1)
    .executeTakeFirst()
  return row ? { value: row.value, finishedAt: row.finished_at } : null
}
```
