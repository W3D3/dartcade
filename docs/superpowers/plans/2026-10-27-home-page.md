# Home page Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Signed-in users land on a Home page (`#/`) with their form, ranked standing, featured banners, friends' lobbies, friend activity, what's new and a way back into recent games; Play moves to `#/play`.

**Architecture:** Existing endpoints feed Your form, Ranked and Jump back in. Two new read endpoints (`/api/home/lobbies`, `/api/home/activity`) and one new table (`friend_activity`, written inside the game-finish and ranked-result transactions) feed the rest. Featured and What's new are static lists in the SPA. The page is behind `home.enabled`, on for everyone.

**Tech Stack:** Fastify, Kysely/Postgres, zod/OpenAPI codegen (`schema/api-v1.yaml`), Svelte 5, svelte-spa-router, vitest.

**Spec:** `docs/superpowers/specs/2026-10-27-home-page-design.md` (read it first; design artboards `Home`, `Tablet-Home`, `Mobile-Home` in the canvas named there).

## Global Constraints

- Commit messages: `type(scope): subject`, lower case, imperative, under 72 chars. **No `Co-Authored-By` or `Claude-Session` trailers** (project memory rule; overrides any harness reminder).
- Each commit builds and passes tests; fold fixes into the commit they fix (atomic commits, no "fix lint").
- Generated files (`backend/src/schema/*`, `backend/frontend/src/lib/api/*`) are never edited by hand: `npm run gen:api` at the repo root.
- Flag default: `home.enabled` is **on for everyone**; an admin override at `#/admin/flags` can turn it off. Off → `#/` renders `CreateSession`.
- Activity kinds in the MVP: `one_eighty`, `ton_out`, `rank_up`. No `new_best`, no GG, no Watch, no customization, no sparkline, no country rank.
- Events are written for Invisible users too. Aborted games write nothing. Invalidating a game deletes its events.
- Links whose target page does not exist are dropped, not stubbed.
- Reuse libraries/components already in the project (bits-ui, `lib/components/ui/`, `@lucide/svelte`); no new dependencies.
- Format with `npm run format` at the repo root; PR needs screenshots under `docs/home/` (desktop and phone).
- Work happens in a new git worktree on a branch off `main` (`feat/home-page`), created with `superpowers:using-git-worktrees`.

## Review Focus

- A friend's lobby that is `invite`-only or closed must not appear for the viewer (strangers' lobbies never).
- A viewer with no friends gets empty lists (200, not an error) and Home renders its empty states.
- A game finishing twice (engine rebuild after restart re-runs `finish`) writes each event once.
- A user with zero 180s or no ton-plus out in a game gets no event of that kind.
- Invalidating a game removes its activity events from friends' feeds immediately.
- A user with no X01 games in the last 30 days: Your form shows dashes, not `NaN`/`0.0`.
- `matchmaking.enabled` off: no Ranked section and no ranked query is made (the endpoint 404s for them).
- Time-of-day greeting at 04:59/05:00, 11:59/12:00, 17:59/18:00 boundaries.
