# Teams Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Team games in lobbies (Team A vs Team B sharing a score), starting with X01, built as a shared building block other games can opt into.

**Architecture:** Each player stays a seat; a game that supports teams maps seats to team indices (`cfg.teams`) and keeps its scoring per team. Shared pure helpers (`backend/src/games/teams.ts`) build the turn rotation, rank teams and extend forfeits to whole teams. The lobby stores each person's team on the server and turns it into seats and `cfg.teams` at start; the screens only read `team` and the game's `teams` view.

**Tech Stack:** Fastify + Kysely + Postgres, Svelte 5 runes + Tailwind v4, vitest, schemas in `schema/` generated with `npm run gen:api`.

**Spec:** `docs/superpowers/specs/2026-10-03-teams-design.md`

## Global Constraints

- **The server decides, the screens read:** team assignment, the split, newcomers, the turn order and placements are server rules; no frontend code counts people or decides teams.
- Generated files change only through `npm run gen:api` at the repo root (and `npm run lint:api` stays clean).
- No TypeScript casts in non-test code. Frontend `svelte-check` 0 errors and 0 warnings; `npm run lint` exits 0 in backend and frontend.
- Games stay pure reducers: anything random comes from the `rng` passed to `init`.
- Migrations: add `011_*.sql`; never edit a shipped one (CI checks it).
- Two teams only, ids `'A'`/`'B'`, names "Team A"/"Team B". Inside a game, teams are indices (0 = A, 1 = B).
- Singles must behave exactly as today: every existing test passes unchanged.
- Components over markup: extract `TeamPanel`, `TeamsPanel`; reuse kit `Button`, `SegmentedControl`, `Avatar`.
- Copy: plain, short; "manual entry", never "by hand".
- Run npm with the node on PATH (mise's Node 22 isn't installed in the sandbox); never `npm install`. Backend DB tests: `TEST_DATABASE_URL=postgres://dartgames:dev@172.18.0.2:5432/dartcade_lb_test npm test` in `backend/`.

## Review Focus

1. **Uneven teams (2v1):** the single player throws every other turn (A1 B1 A2 B1 …), rounds and the round limit still count correctly, and the leg starter alternates teams. → Task 2 tests `turnOrder` uneven and Task 3 "2v1 game".
2. **Bust and checkout by the second player of a team:** a bust reverts the team's score to where the team stood at the start of that player's visit; a checkout by either player wins the leg for the team. → Task 3 tests.
3. **Forfeit in a team game:** the forfeiter's teammates are placed last with them; a host who controls seats in both teams can't forfeit (nobody left to lose to). → Task 4 tests.
4. **Someone sits out or leaves while Teams is set:** their team spot is kept (back in → same team); leaving removes them; a guest added later lands on the smaller team. → Task 5 tests.
5. **Switching the next game from Teams back to Singles and to ATC:** teams are kept on the people but ignored; ATC never gets `format: 'teams'` (no `teams` flag). → Task 5 test.

- [ ] **Step 3: Implement** `teams.ts`:
  ```ts
  /** What a game that supports teams reads from its config (see the teams design). */
  export type TeamsConfig = { format?: 'singles' | 'teams'; teams?: number[]; teamStart?: 'first' | 'random' }

  export function teamOfSeats(cfg: TeamsConfig, seatCount: number): number[] {
    const own = Array.from({ length: seatCount }, (_, i) => i)
    if (cfg.format !== 'teams' || !cfg.teams || cfg.teams.length !== seatCount) return own
    return [...cfg.teams]
  }

  export const teamCount = (teamOf: number[]): number => teamOf.length === 0 ? 0 : Math.max(...teamOf) + 1

  export function seatsByTeam(teamOf: number[]): number[][] {
    const out: number[][] = Array.from({ length: teamCount(teamOf) }, () => [])
    teamOf.forEach((t, seat) => out[t].push(seat))
    return out
  }

  export function turnOrder(teamOf: number[], startTeam: number): number[] {
    const teams = seatsByTeam(teamOf)
    const n = teams.length
    const rounds = Math.max(...teams.map(t => t.length))
    const order: number[] = []
    for (let r = 0; r < rounds; r++) {
      for (let k = 0; k < n; k++) {
        const team = teams[(startTeam + k) % n]
        order.push(team[r % team.length])
      }
    }
    return order
  }

  export function seatPlacements(teamOf: number[], teamPlacements: number[]): number[] {
    return teamOf.map(t => teamPlacements[t])
  }

  export function forfeitedTeamSeats(teamOf: number[], forfeited: ReadonlySet<number>): Set<number> {
    const teams = new Set([...forfeited].map(seat => teamOf[seat]))
    return new Set(teamOf.flatMap((t, seat) => teams.has(t) ? [seat] : []))
  }
  ```
  (In singles `turnOrder` yields one round of all seats starting at `startTeam`, which equals today's rotation.)
