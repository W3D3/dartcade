# E2E Smoke Test Suite Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a Playwright e2e smoke test suite covering auth, boards, session creation, ATC manual entry, and X01 bust detection — running on every PR with `continue-on-error: true`.

**Architecture:** Playwright tests live in `e2e/` at repo root. A `docker-compose.e2e.yaml` spins up postgres + backend + frontend (no bridge). `globalSetup`/`globalTeardown` manage compose lifecycle. An auth fixture creates a unique user per worker via the API so tests run in parallel without collisions.

**Tech Stack:** `@playwright/test`, Docker Compose v2, TypeScript

**Spec:** `docs/superpowers/specs/2026-09-28-e2e-tests-design.md`

**Worktree:** `/home/wedenigc/Dev/dartcade/.claude/worktrees/feat+e2e-tests`

## Global Constraints

- Playwright `@playwright/test` ≥ 1.49
- No `page.waitForTimeout` — use `waitForURL`, `waitForSelector`, `expect.toBeVisible`
- 1 retry on CI, 0 locally
- Each test worker gets its own user: email pattern `e2e-{workerIndex}-{timestamp}@test.local`
- CI job uses `continue-on-error: true` — e2e failures are visible but never block merges
- All files created in the worktree: `/home/wedenigc/Dev/dartcade/.claude/worktrees/feat+e2e-tests`

## Review Focus

- **Better-auth CSRF on API requests:** `POST /api/auth/sign-in/email` made by Playwright's request context must include `Origin: http://localhost:5173`; missing header → 403 → auth fixture silently fails and all other tests fail with "not logged in". Test: the auth fixture in Task 4 asserts the sign-in response is `ok`.
- **Vite proxy cookie domain:** session cookie is set by backend via the Vite proxy; the browser sees the cookie for `localhost:5173`. If `page.request.post()` doesn't go through the proxy, cookies land on `localhost:3000` and the SPA never sees them. Test: `create-session.spec.ts` navigates directly to `/#/` and checks it doesn't redirect to `/#/login`.
- **Boardless session view mode auto-switch:** GameDisplay auto-switches to `entry` view when `boardId === null`. If this breaks, DartEntryPanel won't be visible, and game-atc/game-x01 tests fail. Test: both game specs assert the "Single" multiplier button is visible immediately after navigation without clicking "Enter".
- **X01 bust trigger with double-out:** the bust test relies on score reaching 1 (unfinishable in double-out mode, the default). If the default outMode changes to straight, score 1 is no longer a bust and the test won't see the bust badge until the score goes negative. Test: game-x01.spec.ts uses 2×T20 in round 2 — if the badge doesn't appear, the first suspect is a changed default outMode.
- **docker-compose `--wait` support:** requires Docker Compose v2.1+. If the runner has an older version, `globalSetup` will fail immediately. Test: add a `docker compose version` check in `globalSetup` and throw a clear error if v2 is not found.

```typescript
import { execSync } from 'child_process'
import path from 'path'

const root = path.resolve(import.meta.dirname, '..')

export default async function setup() {
  // Verify Docker Compose v2
  try {
    const ver = execSync('docker compose version', { encoding: 'utf8' })
    if (!ver.includes('v2') && !ver.match(/\d+\.\d+\.\d+/)) {
      throw new Error('Docker Compose v2 not found')
    }
  } catch {
    throw new Error('Docker Compose v2 is required. Run: docker compose version')
  }

  console.log('[e2e] Starting test environment...')
  execSync('docker compose -f docker-compose.e2e.yaml up -d --wait', {
    cwd: root,
    stdio: 'inherit',
  })
  console.log('[e2e] Test environment ready.')
}
```

```typescript
import { test as base, expect } from '@playwright/test'
import type { Page } from '@playwright/test'

export { expect }

export const test = base.extend<{ authedPage: Page }>({
  authedPage: async ({ page }, use, testInfo) => {
    const ts = Date.now()
    const email = `e2e-${testInfo.workerIndex}-${ts}@test.local`
    const password = 'TestPass1!'
    const name = `E2E-${testInfo.workerIndex}`

    // Register via API (Origin header satisfies better-auth CSRF check)
    const signUp = await page.request.post('http://localhost:5173/api/auth/sign-up/email', {
      data: { name, email, password },
      headers: { Origin: 'http://localhost:5173' },
    })
    expect(signUp.ok(), `sign-up failed: ${signUp.status()} ${await signUp.text()}`).toBeTruthy()

    // Sign in — session cookie is set for localhost:5173 via Vite proxy
    const signIn = await page.request.post('http://localhost:5173/api/auth/sign-in/email', {
      data: { email, password },
      headers: { Origin: 'http://localhost:5173' },
    })
    expect(signIn.ok(), `sign-in failed: ${signIn.status()} ${await signIn.text()}`).toBeTruthy()

    await use(page)
  },
})
```

## Task 9: game-x01.spec.ts

**Files:**

**Interfaces:**

- Notes: X01 bust test uses solo player, 301 score, straight-out (bust triggers when score goes negative). Flow: 3×T20=180 (score→121) + takeout → 3×T20=180 (third T20 triggers bust: 1-60=-59).

- [ ] **Step 1: Create `e2e/tests/game-x01.spec.ts`**

```typescript
import { test, expect } from '../fixtures/auth.js'

test('X01 manual dart entry shows bust state', async ({ authedPage: page }) => {
  await page.goto('/#/')

  // Select X01 (default mode is ATC)
  await page.click('button:has-text("X01")')

  // Switch start score to 301 (default is 501)
  await page.click('button:has-text("301")')

  await page.click('button:has-text("Game on")')
  await page.waitForURL('**/#/session/**')

  // Entry view auto-activates for boardless sessions
  await expect(page.locator('button[aria-label="Single 1"]')).toBeVisible()

  // Round 1: throw T20 × 3 = 180. Score: 301 − 180 = 121. Takeout.
  // DartEntryPanel multiplier buttons: "Single" | "Double" | "Triple"
  const tripleBtn = page.locator('button:has-text("Triple")').first()
  await tripleBtn.click()
  await page.click('button[aria-label="Triple 20"]')
  await tripleBtn.click()
  await page.click('button[aria-label="Triple 20"]')
  await tripleBtn.click()
  await page.click('button[aria-label="Triple 20"]')

  // End the visit (CorrectionPanel button)
  await page.click('button:has-text("Takeout · next player")')

  // Round 2: default outMode is "double" — score 1 is unfinishable → bust.
  // T20 → 121−60=61.  T20 → 61−60=1 → bust fires immediately.
  await tripleBtn.click()
  await page.click('button[aria-label="Triple 20"]')
  await tripleBtn.click()
  await page.click('button[aria-label="Triple 20"]')

  // Bust badge visible in x01 player stats view
  await expect(page.locator('text=Bust').first()).toBeVisible()
})
```
