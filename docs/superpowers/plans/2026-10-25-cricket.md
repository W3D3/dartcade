## Review Focus

1. **Cut-throat: a non-thrower wins.** Team C has opened everything with 50 points, B has 40 and
   A, throwing, has 60. A's dart adds points to B. C now has the fewest points and must win the
   leg on A's dart. Task 1 tests `legWinner` for it.
2. **A leg won mid-visit:** the darts after the winning dart are ignored, `visitLocked` is true,
   and the takeout commits the leg (the next leg or the match). On a camera board the engine
   holds the deciding takeout for Finish. Task 2 tests the reducer; Task 3 adds an engine test.
3. **A correction that undoes the opening dart:** T20 then T20 scores 60. Correcting the first
   dart to S1 must, on refold, leave 20 opened with 20 points (the second dart's last mark).
   Task 2 has the refold test.
4. **Teams share marks:** in a 2v2, seat 2's marks land on Team A's row. MPR stays per seat.
   `summarize` gives both seats of a team the same placement. Tasks 2 and 4.
5. **Forfeit mid-leg:** `summarize` with `winner: null` ranks by legs, then points (the reverse
   in cut-throat), then targets opened, and never throws. Task 4.

```ts
// Cricket's rules, pure: what a dart is worth in marks, what marks do to the board, and who has
// won the leg. Shared by the reducer, the bot and the tests (see games/cricket.ts).
import type { Dart } from '../session/types.js'

export type CricketMode = 'standard' | 'cutthroat'

export const TARGETS: readonly number[] = [20, 19, 18, 17, 16, 15, 25]
/** Marks that open a target. */
export const OPEN = 3

/** Per team: marks per target (0–OPEN) and points. */
export type Marks = { targets: readonly number[]; marks: number[][]; points: number[] }

export function emptyMarks(teams: number, targets: readonly number[] = TARGETS): Marks {
  return { targets, marks: Array.from({ length: teams }, () => targets.map(() => 0)), points: Array<number>(teams).fill(0) }
}

/** The target a dart hits and its marks; null for a miss or a number that isn't a target. */
export function marksFor(dart: Dart, targets: readonly number[]): { target: number; marks: number } | null {
  const { number, multiplier } = dart.segment
  if (multiplier === 0) return null
  // The bullseye arrives as 50 (Board Manager, manual entry) or as a double 25
  const bull = number === 50 || number === 25
  const target = targets.indexOf(bull ? 25 : number)
  if (target < 0) return null
  return { target, marks: number === 50 ? 2 : multiplier }
}

/** `n` marks for `team` on `target`: they open it first, then score while an opponent hasn't opened it. */
export function applyMarks(b: Marks, team: number, target: number, n: number, mode: CricketMode): { board: Marks; counted: number; scored: number } {
  const have = b.marks[team][target]
  const opening = Math.min(n, OPEN - have)
  const extra = n - opening
  const stillOpen = b.marks.flatMap((row, t) => (t !== team && row[target] < OPEN ? [t] : []))
  const scored = stillOpen.length > 0 ? extra * b.targets[target] : 0
  const marks = b.marks.map((row, t) => (t === team ? row.map((m, i) => (i === target ? m + opening : m)) : row))
  const points = b.points.map((p, t) => {
    if (mode === 'standard') return t === team ? p + scored : p
    return stillOpen.includes(t) ? p + scored : p
  })
  return { board: { ...b, marks, points }, counted: opening + (scored > 0 ? extra : 0), scored }
}

/** The team that has won the leg: every target opened and not behind (cut-throat: not ahead). The thrower's team first. */
export function legWinner(b: Marks, thrower: number, mode: CricketMode): number | null {
  const wins = (t: number) => {
    if (!b.marks[t].every(m => m >= OPEN)) return false
    const others = b.points.filter((_, i) => i !== t)
    return mode === 'standard' ? others.every(p => b.points[t] >= p) : others.every(p => b.points[t] <= p)
  }
  if (wins(thrower)) return thrower
  const other = b.marks.findIndex((_, t) => t !== thrower && wins(t))
  return other < 0 ? null : other
}
```

**Rules the reducer implements** (copy X01's structure; reuse its `position`/`nextTurn`/`legStart`
shape, written for this state):

- **`init`:**
  - `teamOf = teamOfSeats(cfg, n)`; `order = turnOrder(teamOf, startTeam)`, with `startTeam`
    worked out as in X01 (`teamStart: 'random'` uses `rng`).
  - `board = emptyMarks(teamCount(teamOf))`. `legs` all 0, `round` 1.
  - Per-seat arrays are zeroed: `targetMarks` is `n × 7` zeros, `lastVisit` all `null`.
- **`visit.opened`:** set `visitDarts`, `visitMarks` and `visitPoints` to 0.
- **`dart.detected`:**
  - If `phase === 'finished'` or `legWonBy !== null`, return `s` unchanged. Darts after the
    winning dart don't count.
  - Otherwise `visitDarts + 1`, and `m = marksFor(dart, board.targets)`. With no marks, only
    the dart is counted.
  - Otherwise `applyMarks` for the thrower's team. Add `counted` to `visitMarks`, `marksScored[cp]`
    and `targetMarks[cp][m.target]`, and `scored` to `visitPoints`.
  - Then `legWonBy = legWinner(board, team, mode)`.
- **`takeout.finished` / `visit.cleared`:**
  - Commit the visit: the record `{ seat, marks: visitMarks, points: visitPoints, darts: visitDarts }`
    goes onto `legVisits` and `lastVisit[cp]`, and `dartsThrown[cp] += visitDarts`.
  - If `legWonBy !== null`, the winning team's `legs` goes up by 1. When that reaches `firstTo`:
    `winner = legWonBy`, `phase = 'finished'`. Otherwise start a fresh leg: `emptyMarks`,
    `legWonBy = null`, `round = 1`, `legVisits = []`, and the turn at `legStart(order, legs)`.
  - Otherwise advance with `nextTurn`. A new round starts when the turn gets back to the leg's start.
  - Reset the visit counters either way.
- `getLeg`: the sum of `legs`. `throwOrder`: `[...new Set(s.order)]`. `teamsOf`: `s.teamOf`.
- `onUserAction`: return `s`. `version: 1`. `teams: true`. `validate`: X01's `validateTeams`.
  Move it to `teams.ts` as `validateTwoTeams(cfg, players)` and have X01 call it too, rather than
  copying it.

  - `format`, `bullOff`, `botSpeed`, `firstTo`: X01's entries, copied.
  - `mode`: label "Mode", tooltip "Standard: points go to you. Cut-throat: points go to every

```ts
export function cricketTarget(b: Marks, team: number, mode: CricketMode): string {
  const n = b.targets.length
  const others = b.marks.map((_, t) => t).filter(t => t !== team)
  const mine = (i: number) => b.marks[team][i] >= OPEN
  const someoneOpen = (i: number) => others.some(t => b.marks[t][i] >= OPEN)
  const someoneShut = (i: number) => others.some(t => b.marks[t][i] < OPEN)
  const label = (i: number) => (b.targets[i] === 25 ? 'Bull' : `T${b.targets[i]}`)
  const first = (ok: (i: number) => boolean) => Array.from({ length: n }, (_, i) => i).find(ok)
  const scoring = first(i => mine(i) && someoneShut(i))
  const defend = first(i => !mine(i) && someoneOpen(i))
  const close = first(i => !mine(i))
  if (mode === 'standard') {
    const behind = others.some(t => b.points[t] > b.points[team])
    const pick = (behind ? scoring : undefined) ?? defend ?? close ?? scoring
    return pick === undefined ? 'T20' : label(pick)
  }
  const pick = defend ?? scoring ?? close
  return pick === undefined ? 'T20' : label(pick)
}
```
