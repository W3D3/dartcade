# 121 Checkout

A checkout drill. You get nine darts to check out 121. Make it and the next target is 122; miss
and you drop back. The design canvas has the solo screens: `P121-Game`, `P121-Made`,
`P121-Missed`, `P121-Phone` and `P121-Summary`. This spec adds multiplayer on top of them.

## Rules

- **Setup.** Start target (default 121), tries per player (default 10), darts per try (3 / 6 / 9 / 12,
  default 9), out rule (straight / double / master, default double), miss rule (back to start /
  down one / stay, default back to start), 3-dart lock (off / on, default off), bull off
  (off / wdc / pdc, default off, as in X01). Bull value isn't an option: the bull is 25/50.
- **A try.** The player throws at the target until it reaches exactly 0 under the out rule, or
  the try's darts run out. A bust (below 0, a dead-end 1, or 0 without the out rule) ends the
  visit and puts the score back to where the visit started. The try then goes on with the
  visits it has left. A checkout mid-visit ends the visit; the leftover darts aren't needed.
- **Next target.** A made try moves the target up by 1. A missed one follows the miss rule:
  back to the start target, the missed target minus 1 (never below the start target), or the
  same target again.
- **3-dart lock.** With the lock on, a target checked out in 3 darts or fewer becomes a floor.
  After that, a miss never drops the player below it, whatever the miss rule.
- **Give up.** The "Give up this try" button ends the current try as missed (`p121_give_up`). It
  works only between visits: while darts are in the board it's disabled ("Take your darts out
  first"), because the board's takeout would otherwise commit an empty visit.
- **Turns.** Turns rotate per visit, as in X01. Each player throws one visit of their own try,
  then the next player throws. A try can span up to three of the player's turns. A player who
  has used all their tries is skipped. The game ends when every player is done.
- **Winner.** The highest target checked out wins. Ties go to more checkouts, then fewer darts
  over all made tries. A solo game ends with the player in first place.
- **Throwing order.** `withBullOff`, as in X01. With 2 or more players and bull off on, a bull
  off sets the order.

## Backend

- **`backend/src/games/p121.ts`**, a `GameModule` wrapped with `withBullOff`, registered in
  `games/index.ts`.
  - State per seat: the finished tries (target, made, darts used, finishing dart, visits), the
    current try (target, points left, darts left), and the lock floor. Plus the turn index.
  - `nextTarget(target, made, dartsUsed, cfg, floor)` is a pure function holding the miss rules
    and the lock. It returns the next target and the new floor.
  - The bust and out-rule checks match X01's. They're shared with X01 if that's a small
    extraction, and copied otherwise.
  - `summarize`: placement (the winner rule above; for a forfeit, the forfeit placements) and the
    stats `highestMade`, `checkouts`, `tries`, `avgDarts` and `bestRun`. It works on a game that
    isn't finished.
  - `detail()` (`P121Detail` in `schema/api-v1.yaml`, a branch of `GameDetail.detail`), per seat:
    the tries (target, made, darts), the finishing doubles (hits and attempts per double, where
    an attempt is a dart thrown when `checkoutHint` says one dart can finish), the darts per
    checkout counts, the best run (most made in a row, with its first and last target), the
    highest target reached, and the fastest checkout (darts and target).
  - `matchStats()`: rows for the details page: checkouts, highest made, average darts, fastest.
  - `getLeg` is left out: 121 has no legs.
- **Flag.** `gamemode.p121.enabled` in `backend/src/flags/definitions.ts`, on for admins only,
  like minigolf. The `p121` entry in `lib/gameModes.ts` becomes available, gets
  `glyph: '121'`, and gets this flag.
- **All-time best.** `getBestStat(db, userId, mode, key)` in `db/history.ts` returns the highest
  value of one stat across the user's finished games of a mode, with its `finishedAt`, or null.
  It's served at `GET /api/games/best?mode=&stat=` (in `schema/api-v1.yaml`), for the signed-in
  user only.

## Snapshot

`P121Game` in `schema/game-ws-v1.json` (a branch of `Snapshot`), then `npm run gen:api`:

- `cfg`: the setup.
- `seats`: per seat, the current try (number, target, points left, darts left, this visit's
  darts and scores), the ladder (target and result of each finished try), made, highest made,
  average darts, and the lock floor.
- `current` (whose turn it is), and `lastResult`: the try that just ended (made or missed, the
  target, darts, the next target), which drives the made and missed banners.
- The checkout route comes from `checkoutHint` in the frontend, as in X01.

## Frontend

- **Header** (`lib/gameViews/`): the title "121 CHECKOUT" and a meta line like "Try 4 of 10 ·
  9 darts · double out".
- **Components** in `lib/components/p121/`:
  - `P121PlayerCard`: the target, the big number left, dart pips grouped in threes, the hint
    ("Hit D12 to make it and move up to 124."), the visits so far, and the made or missed banner.
  - `P121Ladder`: the vertical list (desktop solo) and the row of dots (phone, and the cards in
    multiplayer).
  - `P121SessionPanel`: made, highest and average darts, the ladder, "N more tries after this
    one", and Highest target ever.
  - `P121Summary`: the end-of-game screen, laid out like `P121-Summary`. With 2 or more players
    it adds the standings at the top and a picker for whose summary to show, set to the viewer
    first. Highest target ever is the viewer's own.
- **Layouts** in `GameDisplay.svelte`:
  - Solo: as drawn. Player card on the left, the board with This visit and the three route
    slots in the middle, the session panel on the right. On a phone, it follows `P121-Phone`.
  - 2 players: a player card on each side of the board, each with the dot ladder. The current
    player's card has the lime border. The session panel isn't shown.
  - 3 or more: the board on one side, stacked player rows (name, target, points left, dot
    ladder) on the other.
- **End.** When a p121 game finishes, GameDisplay shows `P121Summary` in place of `WinScreen`.
  It's fed by `GET /api/games/{id}` (`detail` and `stats`) and has the buttons from
  `winActions()`. The Match details page uses the same `P121Summary` as its 121 section.
- **Highest target ever** is fetched from `/api/games/best` once per screen, for the viewer only.
  The value and the date are shown ("131 · 2 Oct"). It's hidden when there's none.
- Undo goes through the existing correction flow. The route slots reuse `dartSlots.ts`.

## Not in scope

Bots, teams, caller lines specific to 121, and the all-time best of other players.
