# English (Adam) — built-in caller voice

These audio clips were generated for dartcade using
[Kokoro-82M](https://huggingface.co/hexgrad/Kokoro-82M) (voice `am_adam`), an
open text-to-speech model released under the Apache License 2.0. Kokoro-82M
was trained on permissive/non-copyrighted audio.

Generation used [`kokoro-js`](https://www.npmjs.com/package/kokoro-js)
(version 1.2.1, Apache License 2.0) running the ONNX build of the model,
[`onnx-community/Kokoro-82M-v1.0-ONNX`](https://huggingface.co/onnx-community/Kokoro-82M-v1.0-ONNX)
(q8 quantisation), entirely on CPU via the generator script in
`scripts/caller-voice/`.
